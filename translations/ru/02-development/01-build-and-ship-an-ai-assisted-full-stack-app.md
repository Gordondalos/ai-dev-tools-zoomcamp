# Создание и выпуск full-stack-приложения с помощью ИИ

[Оригинал материала](https://github.com/Gordondalos/ai-dev-tools-zoomcamp/blob/b47dff65161c878d095e288e9f9e5b907f5aa3c6/02-development/01-build-and-ship-an-ai-assisted-full-stack-app.md)

<a id="overview"></a>

## Обзор

В этом модуле вы создадите полноценное работающее приложение с помощью ИИ. Основным проектом остаётся небольшое приложение Snake Arena: оно наглядное, интерактивное и при этом требует основных составляющих реальной системы:

- спецификации продукта
- фронтенда
- контракта OpenAPI
- бэкенда
- базы данных
- тестов

Цель не в том, чтобы позволить ИИ-инструменту бесконтрольно создать всё приложение. Цель — отработать управляемый процесс, в котором ИИ помогает двигаться быстрее, а вы проверяете каждый шаг.

В конце модуля у вас будет приложение, которое работает на вашем компьютере: фронтенд и бэкенд взаимодействуют по определённому контракту, а данные сохраняются в SQLite. Всё необходимое, чтобы сделать приложение доступным другим людям, — интеграционные тесты, контейнеры, CI, развёртывание и CI/CD — рассматривается в [модуле 3](../03-deployment/01-test-containerize-and-deploy-an-ai-assisted-app.md).

Вы научитесь:

- Писать небольшую спецификацию продукта с пользовательскими историями, критериями приёмки и перечнем того, что не входит в задачи продукта, прежде чем генерировать код
- Создавать прототип фронтенда с помощью ИИ-инструмента (Lovable, Bolt, Cursor, Claude Code, Codex и других), затем переносить его в обычный рабочий процесс с репозиторием и делать удобным для сопровождения
- Определять контракт OpenAPI как единый источник истины для фронтенда и бэкенда
- Реализовывать бэкенд на FastAPI по контракту, начиная с имитации базы данных и тестов для основных эндпоинтов
- Заменять имитацию хранилища на SQLite, сохраняя независимость приложения от конкретной базы данных, чтобы впоследствии перейти на Postgres без переписывания приложения
- Добавлять модульные тесты и тесты фронтенда, покрывающие поведение, описанное в спецификации и контракте

Пример приложения:

- https://github.com/alexeygrigorev/interview-canvas-share

Краткое содержание модуля: сопроводительная статья показывает, как с нуля создать приложение для совместной работы на собеседованиях по проектированию систем. От прототипа фронтенда с имитацией вызовов она переходит к контракту OpenAPI, бэкенду на FastAPI, совместной работе через WebSocket и сохранению данных в SQLite. Каждый этап проверяется тестами перед переходом к следующему.

## Результаты работы по модулю

К концу модуля 2 в вашем репозитории должны быть:

```text
product-spec.md
AGENTS.md or equivalent
frontend/
backend/
openapi.yaml
tests/
docs/ai-usage-report.md
```

Примечание: `or equivalent` означает «или аналогичный файл». Имена файлов и каталогов в примере сохранены без изменений.

Приложение должно запускаться локально по инструкции из README, сохранять данные в SQLite и успешно проходить собственные тесты.
