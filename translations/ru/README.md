<a id="about-the-course"></a>

## О курсе

AI Dev Tools Zoomcamp — бесплатный практический курс для разработчиков и технических специалистов по данным, которые хотят освоить дисциплинированную разработку ПО с помощью ИИ.

В основе курса лежит один рабочий процесс:

> Давайте инструментам ИИ подходящий контекст, поручайте им подходящие задачи, проверяйте то, что они создают, тестируйте результат и выпускайте программное обеспечение с защитными ограничениями.

Вы сравните современные инструменты ИИ для разработчиков, создадите и развернёте full-stack-приложение, наладите его эксплуатацию с наблюдаемостью и реагированием на инциденты при помощи агентов, а также расширите возможности агентов разработки с помощью MCP и повторно используемых компонентов.

Курс не ограничивается промпт-инжинирингом и не посвящён обучению моделей или созданию RAG-систем. Главное здесь — повседневная разработка ПО с ИИ-ассистентами и агентами, тестами, CI/CD, развёртыванием, документацией и проверкой кода.

<a id="who-should-join"></a>

## Для кого этот курс

Курс подойдёт вам, если вы:

- Уже умеете писать простой код на Python, JavaScript, TypeScript или похожем языке.
- Хотите профессионально использовать инструменты ИИ для программирования, а не только получать отдельные фрагменты кода.
- Хотите выстроить воспроизводимый процесс планирования, составления запросов, проверки, тестирования, отладки и выпуска кода.
- Заботитесь о поддерживаемости, тестах, развёртывании, документации и ревью кода.
- Хотите создать проект, демонстрирующий практические навыки разработки с ИИ.
- Цените общие сроки потока, поддержку сообщества, взаимное рецензирование и возможность получить сертификат.

Курс особенно полезен разработчикам ПО, ML-инженерам, MLOps-инженерам, AI-инженерам, специалистам по данным, инженерам данных, аналитикам, которые пишут код, и студентам технических специальностей, которым нужен практический проектный опыт.

Курс, вероятно, не подойдёт вам, если вы никогда не программировали, ищете нетехническое введение в ИИ или прежде всего хотите изучать обучение и дообучение моделей, LangChain, векторные базы данных либо RAG.

<a id="prerequisites"></a>

## Предварительные знания

Опыт работы с инструментами ИИ не требуется.

Вы должны:

- Уметь писать простой код на Python, JavaScript, TypeScript или похожем языке.
- Уверенно пользоваться командной строкой.
- Знать основы Git и GitHub.

Будут полезны, но не обязательны:

- Базовые знания веб-разработки.
- Базовое знакомство с Docker.

Не требуются:

- Опыт работы с ИИ-ассистентами или агентами для программирования.
- Мощный компьютер или GPU.

<a id="syllabus"></a>

## Программа

<a id="module-1-ai-native-developer-workflow"></a>

### [Модуль 1. Рабочий процесс разработчика с ИИ в основе](01-ai-native-workflow/01-ai-native-developer-workflow.md)

Узнайте, как с помощью агентов разработки превратить расплывчатую идею продукта в программное обеспечение со спецификацией, реализацией и независимой проверкой.

В этом модуле вы:

- Превратите расплывчатую идею в спецификацию и бэклог конкретных задач.
- Передадите агентам разработки устойчивый контекст через `AGENTS.md`.
- Используете роли PM/инженер/QA, организуя работу через циклы и графы, чтобы реализовать и проверить задачи бэклога.

Результат: вы спроектируете и запустите процесс разработки с ИИ в основе, который проведёт продукт от идеи до реализации и независимой проверки качества.

<a id="module-2-build-and-ship-an-ai-assisted-full-stack-app"></a>

### [Модуль 2. Создание и выпуск full-stack-приложения с помощью ИИ](02-development/01-build-and-ship-an-ai-assisted-full-stack-app.md)

Создайте full-stack-приложение с помощью ИИ-ассистентов для программирования, поочерёдно заменяя компоненты-заглушки настоящими.

Вы:

- Превратите идею в спецификацию, затем создадите прототип фронтенда и контракт OpenAPI.
- Реализуете бэкенд на FastAPI по этому контракту, затем соедините его с фронтендом, добавив аутентификацию и совместную работу в реальном времени.
- Замените временное хранилище на SQLite и добавите тесты.

Результат: работающее full-stack-приложение с обновлениями в реальном времени, постоянным хранением данных, тестами и ясным API-контрактом.

<a id="module-3-test-containerize-and-deploy-an-ai-assisted-app"></a>

### [Модуль 3. Тестирование, контейнеризация и развёртывание приложения, созданного с ИИ](03-deployment/01-test-containerize-and-deploy-an-ai-assisted-app.md)

Перенесите приложение со своего компьютера в общедоступное развёртывание, добавив тесты и проверки доставки, которые проверяют систему целиком.

Вы:

- Контейнеризируете приложение и перейдёте с SQLite на Postgres с помощью Docker Compose.
- Добавите интеграционные и сквозные тесты, в том числе Playwright для сценария совместной работы.
- Развернёте приложение в AWS и настроите конвейер CI/CD в GitHub Actions.

Результат: общедоступное контейнеризированное приложение на Postgres с автоматическими тестами и CI/CD, который выполняет развёртывание только после успешного прохождения тестов.

<a id="module-4-devops-and-observability-for-ai-built-apps"></a>

### [Модуль 4. DevOps и наблюдаемость приложений, созданных с ИИ](04-devops/01-devops-and-observability-for-ai-built-apps.md)

Развёрнутое приложение всё ещё может незаметно давать сбои. Добавьте управление релизами и наблюдаемость, чтобы обнаруживать и расследовать проблемы и реагировать на них.

Вы:

- Разделите среды разработки и эксплуатации, настроив конвейер продвижения версионированных релизов.
- Инструментируете приложение с помощью OpenTelemetry, направив данные в Prometheus, Loki, Tempo и Grafana, и настроите оповещение, по которому можно принять меры.
- Дадите агенту разработки ограниченную роль реагирования на инциденты с доступом только на чтение.

Результат: отдельные процессы для dev/prod, стек наблюдаемости, полезные оповещения и экспериментальный ИИ-агент дежурного реагирования.

<a id="module-5-coding-agent-building-blocks-reusable-skills-and-specialized-subagents"></a>

### [Модуль 5. Компоненты агентов разработки: повторно используемые навыки и специализированные субагенты](05-agent-capabilities/README.md)

Превратите повторяющиеся рабочие процессы и роли в проекте в повторно используемые возможности, которые агенты разработки смогут находить и применять.

Вы:

- Создадите обнаруживаемые навыки с помощью `SKILL.md` и решите, должны ли они быть глобальными или относиться к конкретному проекту.
- Определите узкоспециализированных субагентов, включая роли PM/инженер/QA, чтобы отделить реализацию от независимой проверки.
- Организуете параллельное выполнение задач в изолированных Git worktree.

Результат: повторно используемые навыки, определения субагентов и схема оркестрации для последовательной или параллельной работы над проектом.

> [!NOTE]
> В модуле 5 нет оцениваемого домашнего задания. Вместо него оценивается [результат работы по модулю](05-agent-capabilities/README.md#module-deliverable-agent-extension-pack).

<a id="final-project"></a>

## Итоговый проект

В [итоговом проекте](project/README.md) вы примените рабочий процесс курса к собственному приложению от начала до конца.

Вы:

- Выберете проблему и опишете ожидаемое поведение системы.
- Создадите фронтенд.
- Создадите бэкенд.
- Определите взаимодействие фронтенда и бэкенда с помощью контракта OpenAPI.
- Добавите базу данных или постоянное хранилище.
- Протестируете приложение.
- Контейнеризируете приложение.
- Развернёте его, чтобы другие могли им воспользоваться.
- Задокументируете, как использовали инструменты ИИ, промпты, рабочие процессы, инструкции для агентов, MCP или автоматизацию.

Для получения сертификата в потоке проекты проходят взаимное рецензирование. Участники должны успешно сдать итоговый проект и выполнить обязательные рецензии на проекты других участников.

<a id="are-there-live-classes"></a>

### Есть ли занятия в прямом эфире?

Лекции записаны заранее. Обучение в потоке добавляет общие сроки, оцениваемые домашние задания, таблицу лидеров, взаимное рецензирование, поддержку сообщества и возможность получить сертификат.

<a id="can-i-take-the-course-self-paced"></a>

### Можно ли проходить курс самостоятельно?

Да. Видео и материалы репозитория доступны в любое время. При самостоятельном обучении сертификат не выдаётся, если вы не присоединитесь к потоку.

<a id="do-i-need-a-powerful-computer-or-gpu"></a>

### Нужен ли мощный компьютер или GPU?

Нет. Мощный компьютер или GPU не требуются.

<a id="is-this-course-about-rag-or-model-training"></a>

### Этот курс посвящён RAG или обучению моделей?

Нет. Курс сосредоточен на процессах разработки ПО с ИИ: ассистентах и агентах для программирования, MCP, тестировании, CI/CD, развёртывании, документации, ревью, безопасности, аудите и DevOps.
