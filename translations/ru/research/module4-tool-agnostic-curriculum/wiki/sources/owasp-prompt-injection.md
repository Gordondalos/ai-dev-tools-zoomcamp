# OWASP LLM01:2025: внедрение инструкций (Prompt Injection)

Расположение: https://genai.owasp.org/llmrisk/llm01-prompt-injection/

Кратко: считайте внешний текст недоверенными входными данными и ограничивайте то, какие данные процесс с участием ИИ может раскрывать и какие действия выполнять.

- [FACT owasp-prompt-injection] Внедрение инструкций может происходить через прямой ввод или внешний контент, который обрабатывает модель.
- [FACT owasp-prompt-injection] Рекомендуемые меры включают отделение недоверенного контента, доступ с минимальными привилегиями, контроль ввода/вывода, проверку с имитацией атак и одобрение человеком операций высокого риска.
- [INFERENCE owasp-prompt-injection] Инструкции агента, файлы репозитория, текст задач, логи и описания инструментов следует включать в модель границ доверия, а не считать безобидным контекстом.

Ограничения: это рекомендации по рискам, а не полный стандарт проверки безопасности агента.
