# Текущие официальные репозитории предлагаемых инструментов модуля 4

Основные источники:

- [FACT tool-repositories] https://github.com/The-PR-Agent/pr-agent
- [FACT tool-repositories] https://github.com/semgrep/semgrep/blob/develop/cli/src/semgrep/mcp/README.md

- [FACT tool-repositories] https://github.com/BerriAI/litellm
- [FACT tool-repositories] https://github.com/ollama/ollama

Кратко: каждый инструмент воплощает полезную схему, но настройка конкретного продукта, потоки данных, поведение при выполнении и статус проекта могут меняться независимо от учебной цели.

- [FACT tool-repositories] PR-Agent поддерживает CLI и интеграции с хостингом/git-платформами для описания, проверки, предложений и вопросов; в 2026 году он перешёл в организацию, управляемую сообществом.
- [FACT tool-repositories] Semgrep предоставляет детерминированный статический анализ через CLI и интерфейс MCP, отделяя находки на основе правил от объяснения LLM.
- [FACT tool-repositories] Agent Scan составляет перечень и анализирует агентов, навыки и серверы MCP, но сканирование конфигурации MCP может выполнять команды серверов; удалённый анализ передаёт метаданные/содержимое компонентов в Snyk и требует тщательного выбора изоляции и согласия.
- [FACT tool-repositories] K8sGPT сначала запускает анализаторы и при необходимости использует выбранный бэкенд модели для объяснения находок; поддерживаются фильтры, вывод JSON и анонимизация.
- [FACT tool-repositories] HolmesGPT использует агентный цикл по актуальным источникам наблюдаемости для расследования инцидентов.
- [FACT tool-repositories] LiteLLM предоставляет общий API/шлюз моделей с маршрутизацией, ключами, бюджетами, защитными ограничениями и логированием; Ollama предоставляет локальный API модели.
- [INFERENCE tool-repositories] Переносимые слои: сбор, детерминированный анализ, вероятностное объяснение, применение политики, действие, проверка и артефакты аудита, а не эти семь названий продуктов.

Ограничения: документация репозитория описывает задуманное поведение и может опускать эксплуатационные ограничения. Возможности продуктов, лицензирование и управление проектами зависят от времени; их нужно перепроверить перед записью лабораторных работ.
