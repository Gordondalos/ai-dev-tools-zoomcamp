# Лучшие практики безопасности Model Context Protocol

Расположение: https://modelcontextprotocol.io/docs/tutorials/security/security_best_practices

Кратко: MCP иллюстрирует общие проблемы безопасности инструментов агента: установка кода, делегирование полномочий, работа с учётными данными, получение согласия и сохранение сведений об авторстве действий.

- [FACT mcp-security] Локальные серверы MCP могут выполняться с правами клиента на файловую систему и сеть и создавать риск выполнения кода, вывода данных наружу и потери данных.
- [FACT mcp-security] Рекомендации требуют показывать точную команду, получать явное согласие, использовать изоляцию, ограничивать ресурсы и постепенно выдавать минимально необходимые права.
- [FACT mcp-security] Сквозная передача токенов подрывает применение ограничений, определение автора действий, журналы аудита и целостность границ доверия.
- [INFERENCE mcp-security] Эти меры применимы к скриптам, плагинам, хукам, навыкам и CLI-инструментам, даже когда MCP не используется.

Ограничения: специфичные для протокола детали, например метаданные ресурсов OAuth, не входят в ядро курса для учащихся, использующих только локальные CLI-инструменты.
