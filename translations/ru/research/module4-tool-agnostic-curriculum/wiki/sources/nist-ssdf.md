# NIST Secure Software Development Framework 1.1

Расположение: https://csrc.nist.gov/projects/ssdf

Кратко: SSDF является прямым примером обучения результатам безопасной разработки независимо от конкретных инструментов.

- [FACT nist-ssdf] SSDF представляет собой набор фундаментальных практик безопасной разработки ПО для интеграции в разные реализации SDLC.
- [FACT nist-ssdf] Его практики ориентированы на результат, а примеры реализации служат иллюстрациями и не являются обязательными или исчерпывающими.
- [FACT nist-ssdf] Фреймворк стремится сократить число вносимых уязвимостей, ограничить последствия невыявленных уязвимостей и устранить первопричины, чтобы предотвратить повторение.
- [INFERENCE nist-ssdf] Модуль 4 может использовать ту же схему: устойчивая практика, свидетельства её выполнения, затем взаимозаменяемые примеры реализации.

Ограничения: SSDF адресован производителям ПО в целом и не является специальной программой обучения эксплуатации агентов для программирования.
