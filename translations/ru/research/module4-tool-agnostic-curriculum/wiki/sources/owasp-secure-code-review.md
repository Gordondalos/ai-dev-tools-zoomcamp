# Памятка OWASP по проверке безопасности кода

Расположение: https://cheatsheetseries.owasp.org/cheatsheets/Secure_Code_Review_Cheat_Sheet.html

Кратко: проверка безопасности сочетает контекст приложения, внимание к угрозам, автоматические находки и ручной анализ логики, по которой сканеры не могут дать окончательный ответ.

- [FACT owasp-secure-code-review] Подготовка охватывает архитектуру, бизнес-требования, модели угроз, выявленные проблемы безопасности, активы и функции высокого риска.
- [FACT owasp-secure-code-review] Проверка на основе diff выявляет изменённые компоненты, влияние на защитные меры, назначение изменений и модификации высокого риска.
- [FACT owasp-secure-code-review] Автоматические находки должны определять приоритеты ручной проверки; бизнес-логика, авторизация, переходы состояний и эффективность защитных мер требуют ручного анализа.
- [INFERENCE owasp-secure-code-review] Агент может собрать контекст и предложить находки, но сильная лабораторная работа требует явной записи «утверждение — свидетельства — решение».

Ограничения: памятка обширна и сосредоточена на веб-приложениях; модулю 4 следует выбрать небольшую единообразную процедуру проверки.
