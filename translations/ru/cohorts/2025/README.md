<a id="about-the-course"></a>
## О курсе

AI Dev Tools Zoomcamp — бесплатный практический курс о том, как использовать ИИ-инструменты, чтобы быстрее писать более качественный код. Вы будете работать с ассистентами программирования, агентами, Model-Context Protocol, ИИ для тестирования и CI/CD, а также low-code-автоматизацией, создавая по ходу обучения реальные проекты.

<a id="who-should-join"></a>
## Для кого этот курс

Курс подходит всем, кто хочет использовать ИИ-инструменты для помощи в программировании. Опыт работы с ИИ не нужен: достаточно интереса к применению ИИ-инструментов в своей работе.

<a id="prerequisites"></a>
## Предварительные требования

- Базовое умение программировать (Python, JavaScript или аналогичный язык)
- Предыдущий опыт работы с ИИ-инструментами не требуется

<a id="syllabus"></a>
## Программа

<a id="module-1-introduction-to-vibe-coding--ai-tools-overview"></a>
### [Модуль 1: введение в вайб-кодинг и обзор ИИ-инструментов](01-overview/)

- Разработка с помощью ИИ на примере игры «Змейка» (React + JS)
- Чат-приложения: ChatGPT, Claude, DeepSeek, Microsoft Copilot
- Ассистенты программирования и IDE: Claude Code, GitHub Copilot, Cursor, Pear
- Генераторы проектов: Bolt, Lovable
- Агенты: Anthropic Computer Use, PR Agent и другие

<a id="module-2-end-to-end-project-snake"></a>
### [Модуль 2: проект от начала до конца («Змейка»)](02-end-to-end/)

- Используйте ассистента программирования для проекта от начала до конца
- Создайте «Змейку» на React/TS
- Опишите API с помощью OpenAPI
- Сгенерируйте сервер FastAPI по спецификациям OpenAPI
- Добавьте CI/CD
- Разверните приложение

<a id="module-3-model-context-protocol"></a>
### [Модуль 3: Model-Context Protocol](03-mcp/)

- Расширение возможностей ИИ-ассистентов с помощью инструментов
- Основные серверы: GitHub, Filesystem, DB/SQL, HTTP/API, CI
- Практические процессы: разбор задач репозитория, сводки PR, скриптовые правки, запросы данных
- Локальные и удалённые серверы
- Безопасность и разрешения

<a id="module-4-build-an-ai-coding-agent-django"></a>
### [Модуль 4: создание ИИ-агента программирования (Django)](04-build-coding-agent/)

- Создайте агента программирования, который умеет создавать заготовки проектов и расширять их
- Используйте шаблон Django как основу проекта
- Узнайте, как агенты создают заготовки проектов
- Изучите несколько фреймворков оркестрации агентов
- Результат: приложение Django, созданное и изменённое вашим ИИ-агентом

<a id="module-5-ai-for-testing-cicd--devops"></a>
### [Модуль 5: ИИ для тестирования, CI/CD и DevOps](05-cicd-devops/)

- Ревью и сводки PR с помощью ИИ, подсказки о рисках изменений
- Автоматическая генерация тестов, проверки порогов покрытия и оценка LLM в CI
- Примечания к релизам, черновики журналов изменений и инструкции по развёртыванию
- Разборы инцидентов и ИИ-помощники дежурных инженеров

<a id="module-6-automation-with-low-code-and-no-code-ai-n8n"></a>
### [Модуль 6: автоматизация с Low-Code- и No-Code-ИИ (n8n)](06-automation-lowcode/)

- Установите n8n
- Создавайте публикации для LinkedIn
- Адаптируйте резюме под конкретную вакансию

<a id="faq"></a>
## FAQ

Ниже несколько частых вопросов. Остальные ответы есть в полном [FAQ AI Dev Tools Zoomcamp](https://datatalks.club/faq/ai-dev-tools-zoomcamp.html).

Вопрос: курс действительно бесплатный?<br/>
Ответ: да. Все видео, материалы и домашние задания бесплатны и открыты.

Вопрос: нужен ли предварительный опыт?<br/>
Ответ: опыт работы с ИИ не нужен. Достаточно базового умения программировать на Python, JavaScript или аналогичном языке.

Вопрос: что означает «live cohort»? Есть ли занятия в прямом эфире?<br/>
Ответ: обязательных занятий в прямом эфире нет. Все лекции записаны заранее. «Live» означает дедлайны, оцениваемые домашние задания, таблицу лидеров, взаимную проверку и возможность получить сертификат.

Вопрос: можно ли учиться в своём темпе и получить сертификат?<br/>
Ответ: да, начать можно в любое время. Для получения сертификата необходимо выполнить итоговый проект и 3 взаимные проверки во время потока.
