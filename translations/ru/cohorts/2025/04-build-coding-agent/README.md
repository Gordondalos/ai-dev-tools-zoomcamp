<a id="module-4--create-a-coding-agent"></a>
# Модуль 4 — Создание агента программирования  

[▶️ Запись практикума](https://www.youtube.com/watch?v=Sue_mn0JCsY)  
[📹 Демонстрация приложения TODO с Z-ai](https://www.loom.com/share/b4c47e3491504375b9244ea69fe095df)  

---

<a id="overview"></a>
## Обзор  

- Создайте собственного **агента программирования**, который умеет создавать заготовки проектов и расширять их.  
- Используйте **шаблон Django** как основу проекта.  
- Узнайте, как **агенты создают заготовки проектов**.  
- Изучите несколько **фреймворков оркестрации агентов**.  
- Результат: приложение Django, созданное и изменённое вашим ИИ-агентом.  

---

<a id="prerequisites"></a>
## Предварительные требования  

- Python 3.8+  
- Jupyter Notebook  
- API-ключ OpenAI (обязательно)  
- API-ключ Anthropic (необязательно)  
- Аккаунт GitHub (необязательно, для Codespaces)  

---

<a id="environment"></a>
## Окружение  

- Запускайте локально с Python + Jupyter или в **GitHub Codespaces**.  
- Настройте API-ключи в переменных окружения или секретах Codespaces.  
- Установите необходимые библиотеки:  
	```bash
	pip install jupyter django uv openai toyaikit
	```  

---

<a id="openai-api-recap"></a>
## Повторение OpenAI API  

- Обзор **responses API** для системных и пользовательских промптов.  
- Вызов функций: расширяйте возможности модели собственными функциями Python.  
- Подготовка к подключению инструментов агента.  

---

<a id="django-template-project"></a>
## Проект-шаблон Django  

- Используйте готовый **репозиторий-шаблон Django** или создайте его с нуля.  
- Добавьте `Makefile` с командами установки, миграции и запуска.  
- Создайте шаблоны (`base.html`, `home.html`) с TailwindCSS + Font Awesome.  

---

<a id="building-the-agent"></a>
## Создание агента  

- Определите инструменты: чтение и запись файлов, выполнение команд оболочки, поиск файлов, просмотр дерева файлов.  
- Создайте **developer-промпт**, описывающий проект Django.  
- Запустите агента с помощью [ToyAIKit](https://github.com/alexeygrigorev/toyaikit).  

---

<a id="alternative-frameworks"></a>
## Альтернативные фреймворки  

- **OpenAI Agents SDK** — определяйте инструменты через `@function_tool`, запускайте через `OpenAIAgentsSDKRunner`.  
- **PydanticAI** — лёгкая библиотека агентов с поддержкой инструментов и простым переключением провайдеров.  
- **Z.ai** — API, совместимый с OpenAI, с альтернативными LLM.  

---

<a id="learning-outcomes"></a>
## Результаты обучения  

- Поймёте, как агенты программирования работают как **интеллектуальные инструменты создания заготовок проектов**.  
- Получите практический опыт настройки **Django с помощью ИИ**.  
- Научитесь подключать **инструменты к агентам** в разных фреймворках.  
- Создадите агентов, которые могут адаптироваться к разным **провайдерам LLM**.
