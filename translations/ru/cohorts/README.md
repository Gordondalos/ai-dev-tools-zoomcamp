# Потоки обучения

[Оригинал этой страницы](https://github.com/Gordondalos/ai-dev-tools-zoomcamp/blob/b47dff65161c878d095e288e9f9e5b907f5aa3c6/cohorts/README.md).

Текущая учебная программа, то есть все модули и их уроки, находится **в корне репозитория**, а не здесь. В `cohorts/<year>/` хранится только то, что относится к конкретному запуску курса: даты, домашние задания и, для прошедшего потока, зафиксированная копия программы, по которой учили в тот год.

**Текущий поток — 2026. Исправляйте учебную программу в корне репозитория, а не внутри `cohorts/2026/`.** Это указано единожды, в машиночитаемом виде, в корне: `course.yaml:current_cohort` задаёт текущий поток и должен совпадать с единственным `cohorts/<year>/cohort.yaml`, в котором объявлено `curriculum: current`.

<a id="layout"></a>

## Структура

```
<repo root>/
├── course.yaml                   # course identity, incl. the description
├── 01-ai-native-workflow/        # the directory name IS the module slug
│   ├── module.yaml                 # module identity and unit list
│   ├── README.md                   # GitHub-facing module index, not published
│   └── 01-ai-native-developer-workflow.md  # the module's unit — the stem IS the unit slug
├── ...
└── cohorts/
    ├── README.md                  # this file
    ├── 2026/                      # the directory name IS the cohort identifier
    │   ├── cohort.yaml            # dates, curriculum: current, homework list
    │   ├── README.md              # the human-readable schedule
    │   └── homework/
    │       ├── 01-ai-native-workflow/
    │       │   ├── homework.md    # homework instructions, fixed name
    │       │   └── homework.yaml  # homework identity, due date, form, questions
    │       └── ...
    └── 2025/                      # earlier cohort: frozen, full copy
```

*Пояснение к схеме: `course.yaml` хранит идентификационные данные курса, включая описание; имя каталога модуля является его URL-идентификатором (slug); `module.yaml` содержит данные модуля и список учебных единиц; `README.md` служит индексом модуля для GitHub и не публикуется как урок; имя файла урока без расширения является slug урока. Имя каталога потока является идентификатором потока. `cohort.yaml` содержит даты, признак `curriculum: current` и список домашних заданий; README потока — расписание для читателя. Фиксированное имя `homework.md` используется для инструкций, а `homework.yaml` — для идентификационных данных задания, срока сдачи, формы и вопросов. Каталог 2025 содержит полную зафиксированную копию прежней программы.*

Основную роль играют два правила:

- **Имена определяют идентичность.** Slug модуля — это имя его каталога. В YAML он не повторяется, а переименование каталога изменяет опубликованный URL.
- **Каталог модуля самодостаточен.** Урок находится внутри него. Относительная ссылка не выходит за пределы каталога модуля, кроме переходов к соседнему модулю или в корень репозитория. Для всего, что находится дальше, используется абсолютный URL GitHub.

<a id="current-cohort-vs-frozen-cohort"></a>

## Текущий поток и зафиксированный архив потока

Тип потока указан в его `cohort.yaml`:

- **`curriculum: current`** — поток использует ту программу, которая сейчас находится в корне репозитория. В `cohorts/<year>/` хранятся только даты и домашние задания (`cohorts/<year>/homework/<module>/`). Содержимого модулей или уроков здесь нет, поэтому оно не дублируется и не расходится с корнем.
- **`curriculum: github_archive`** — программа потока существенно отличалась от той, которая сейчас находится в корне, поэтому её зафиксировали: сохранили полную самостоятельную копию всех модулей этого потока. Архив предназначен только для чтения на GitHub и никогда не импортируется повторно как текущие модули или уроки. Пока единственный такой архив в этом репозитории — `cohorts/2025/`. Минимальный `cohort.yaml` добавлен в него позднее. Внутреннее содержимое архива, включая каталоги модулей и README, осталось неизменным материалом эпохи v1 и не перестраивалось под нынешние соглашения.

<a id="note-on-module-5"></a>

## Примечание о модуле 5

Каталог `05-agent-capabilities/` находится в корне репозитория и содержит реальные материалы, но у него нет `module.yaml`, и он пока не включён в учебную программу `cohorts/2026/`. На данный момент это сделано намеренно и соответствует аналогичному открытому вопросу в `machine-learning-zoomcamp` (каталог `11-kserve/`): пронумерованный каталог в корне без `module.yaml` просто не обнаруживается как часть учебной программы. Подключать его к программе или выносить из пространства имён пронумерованных модулей — отдельное решение.

<a id="editing"></a>

## Редактирование

- Исправляйте учебные материалы, то есть уроки, **в корне репозитория**. Именно туда принимаются pull request для текущего потока.
- Исправляйте даты и домашние задания текущего потока в `cohorts/2026/`.
- Зафиксированный `cohorts/2025/` — это архив: его отличия отражают то, чему действительно учили. Переносите туда только исправления фактических ошибок или ошибок, нарушающих работу, и явно отмечайте это.
- Опубликованный slug фиксирован. Его переименование — решение на уровне платформы, а не pull request в репозиторий.

<a id="the-conventions-themselves"></a>

## Сами соглашения

В этом репозитории они не повторяются. Авторитетный источник — `DataTalksClub/zoomcamp-ops`: `STRUCTURE.md` описывает структуру репозитория, а `docs/shared-curriculum-v2.md` — используемую здесь схему с общей программой в корне. Расположенный рядом контракт учебной программы описывает схемы YAML и правила страниц учебных единиц.

Окончательным источником истины служит парсер импорта сайта: при push он явно сообщает об ошибках.
