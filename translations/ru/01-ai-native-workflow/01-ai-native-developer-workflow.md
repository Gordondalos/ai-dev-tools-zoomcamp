# Рабочий процесс разработчика с ИИ в основе

[Оригинал материала](https://github.com/Gordondalos/ai-dev-tools-zoomcamp/blob/b47dff65161c878d095e288e9f9e5b907f5aa3c6/01-ai-native-workflow/01-ai-native-developer-workflow.md)

Инструменты меняются каждый месяц, но мы продолжаем работать примерно так же, как раньше. В этом модуле мы начинаем с расплывчатой идеи продукта, формулируем спецификацию и подготавливаем контекст. Затем реализуем продукт и проводим независимую проверку качества.

Вы изучите:

- Разработку на основе спецификаций
- Проектирование контекста
- Роли менеджера продукта, разработчика и специалиста по тестированию
- Проектирование циклов работы агента
- Проектирование графов взаимодействия агентов

Краткое содержание модуля: сопроводительная статья показывает, как превратить расплывчатую идею в полезную спецификацию, предоставить агенту устойчивый контекст, разбить работу на список задач и использовать отдельные роли менеджера продукта, разработчика и специалиста по тестированию для реализации и проверки результата. Проект weekly-feedback служит предостерегающим примером разработки без спецификации, а затем на примере retroloop последовательно разбираются разработка на основе спецификаций, проектирование циклов и графов взаимодействия агентов.

[Читать статью: «Разработка с ИИ в основе: спецификации, проектирование циклов и графов»](https://aishippingblog.com/p/ai-native-development-specifications)

## Примеры проектов

Мы дважды реализуем идею weekly-feedback, чтобы показать, зачем нужна спецификация:

- [`weekly-feedback`](https://github.com/Gordondalos/ai-dev-tools-zoomcamp/tree/b47dff65161c878d095e288e9f9e5b907f5aa3c6/01-ai-native-workflow/weekly-feedback) — работающая утилита командной строки, которую Claude Code создаёт по одному расплывчатому предложению. Здесь приведены её исходный код и тесты.
- [`retroloop`](https://github.com/alexeygrigorev/retroloop) — приложение на Django для проведения ретроспектив, созданное после подготовки спецификации продукта и проработки упорядоченного списка задач в GitHub.
